# OpenTelemetry Setup

## Purpose
A collection of tools, APIs, and SDKs used to instrument, generate, collect, and export telemetry data.

## Why chosen for this project
Vendor-neutral standard for observability (metrics, logs, traces).

## Install (in Python)
```bash
pip install opentelemetry-api opentelemetry-sdk opentelemetry-instrumentation-fastapi
```

## Verify commands
Check your collector logs or backend (Jaeger/Prometheus).
