# Node.js Setup

## Purpose
The runtime for the Next.js frontend.

## Install
- **Windows/Mac**: [Download from nodejs.org](https://nodejs.org/).
- **Linux**: `curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash - && sudo apt-get install -y nodejs`

## Verify commands
```bash
node --version
npm --version
```
