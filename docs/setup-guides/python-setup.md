# Python Setup

## Purpose
The core programming language for the backend and AI services.

## Install
- **Windows**: [Download from python.org](https://www.python.org/downloads/).
- **Linux**: `sudo apt install python3.11 python3.11-venv python3-pip`
- **Mac**: `brew install python@3.11`

## Verify commands
```bash
python --version
pip --version
```

## Best practices
- Always use a virtual environment (`venv` or `conda`).
- Use `requirements.txt` or `poetry` for dependency management.
