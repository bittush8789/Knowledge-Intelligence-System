# LangGraph Setup

## Purpose
Library for building stateful, multi-actor applications with LLMs.

## Why chosen for this project
Allows for complex AI workflows like iterative retrieval, hallucination checks, and human-in-the-loop.

## Install
```bash
pip install langgraph
```

## Example usage
```python
from langgraph.graph import StateGraph
# Define nodes and edges...
```
